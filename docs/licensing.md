# Licensing and distribution options

**No licence has been selected.** This change adds no LICENSE file and grants
no additional distribution rights. Public source availability is not permission
to copy, modify or redistribute; GitHub access/fork mechanics do not settle
downstream licensing. See
[GitHub licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).

| Option | Tradeoff to evaluate, not legal advice |
| --- | --- |
| MIT | Simple permissive adoption; limited explicit patent treatment compared with Apache 2.0 |
| Apache 2.0 | Permissive with explicit patent grant/termination and notice obligations; evaluate patent and compatibility needs |
| MPL 2.0 | File-level copyleft can preserve modifications while allowing broader combinations; compliance boundaries need review |
| GPL family | Strong copyleft on distributed derivatives; integration/distribution obligations can constrain adopters |
| AGPL family | Network-use obligations address hosted modifications; enterprise compatibility and obligations need careful review |
| Proprietary/dual licensing | More control/commercial options; contributor rights, governance and adoption costs |
| Documentation-specific licence | Separate text permissions may fit, but code examples and generated artefacts need clear boundaries |

Use canonical texts from [OSI](https://opensource.org/licenses) and the
[GNU licence guidance](https://www.gnu.org/licenses/) during an explicit legal/
maintainer decision. This is a comparison, not selection or a legal conclusion.

Before adopting a licence, assess contributor rights, dependencies, embedded
governance assets, provider SDK terms, patent exposure, notices, redistribution
and signing/distribution strategy. The cARL tool's source licence must not be
assumed to license Kredoxi or every generated/embedded artefact automatically.
Record that review separately before public release. Do not add permissive
headers, copy third-party implementation code or publish binaries to resolve an
undecided licensing question.
